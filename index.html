Dictionary mark: refined candidates in both read-aloud modes

The goal is a mark that looks calm at rest and still stays readable when a read-aloud sentence or a highlight runs through it. These candidates are softer and more typographic than the first round: round dots spaced evenly so the first and last dot line up with the word ends, small centred ornaments, and arcs that taper like a pen stroke. All use the text colour except two deep-teal variants. Every mark is pure CSS on the empty 24px word box (baseline 19px from its top). It stays in the 5px band above the read-aloud line and is sized in em.

The read-aloud styling matches the device screenshots. Underline mode draws a 2px ink line at baseline +5…+7. Highlight mode lays a 30% yellow wash over the line box, tinting the text, and draws a 2px yellow line in the same place. User highlights use the same template in their own hue (blue shown). Literata isn’t bundled (no external fonts), so a platform serif stands in.

Recommendation

Pick: 3, the fine dotted underline in the text colour. It’s the calmest mark on a page of prose, and readers already know it as “this word has a definition” (it’s how browsers draw <abbr>). The 1.5px round dots sit 1.5px clear of the read-aloud line, so their texture can’t merge with that solid line in underline mode. Because they use the text colour, any wash tints them exactly as much as the words (5.8:1 under the read-aloud yellow, 6–7.8:1 under user highlights). The first and last dot always line up with the word ends, it’s sized in em, and it follows sepia and dark themes with no extra work.

  • 7, the same dots in deep teal: the prettiest at rest, and the most clearly separate from the ink line. Choose it if you’re willing to set a tint for each theme. It stays at 3.6:1 or better under every wash tested.
  • 11 (or 12 in teal), the long tapered arc: use it if you want more character. It reads like a pen stroke and stays distinct in both modes. Its curve deepens on short words, so it is less uniform than dots.

Avoid the small centred ornaments: 2, 4, 5, 8 and 9. On a phone-width page at device density they shrink under one or two letters and read as accents (dot-below, breve, circumflex below), so the word looks misspelt. This reverses my earlier pick of the three-dot cluster, which has the same problem at 100%. 6 is heavier than it needs to be, 10’s faded ends look like a rendering fault, and 1 is today’s mark that merges with the read-aloud line.

For vertical text, the dot tile in 3 and 7 can run down the side with repeat-y (not rendered here). Checked in headless Chrome at 2.625x density, close to the device, with a fallback serif rather than Literata in Android WebView. Contrast figures use this page’s ink (#212528) and tint (#1d5a73).
